# Family VPN

Family VPN — админ-панель одного администратора для нескольких VPN-серверов WireGuard.

Получатели VPN не регистрируются. Подписок и платежей нет. Конфигурации позже создаёт сам администратор.

## Стек

- Next.js 16
- TypeScript
- App Router
- Tailwind CSS
- SQLite через встроенный `node:sqlite` (Node.js 24)
- ESLint
- npm

## Этот этап

Работают локальная база, вход администратора и сохранение серверов.

Ещё не подключены:

- агент на VPS и установочная команда;
- проверка WireGuard и живой статус Online / Offline;
- трафик, handshake, выпуск `.conf` и QR-код.

Пока этих функций нет, интерфейс прямо пишет, что данных нет. Примерные серверы и графики больше не подставляются.

База создаётся в каталоге `data/` и не коммитится. Другой каталог можно задать переменной `FAMILY_VPN_DATA_DIR`. За обратным прокси дополнительно ставится `FAMILY_VPN_TRUST_PROXY=1`.

Архитектура следующих этапов: [docs/architecture.md](docs/architecture.md).

## Запуск

```bash
npm install
npm run dev
```

При первом открытии панель просит создать пароль администратора. Пароль хранится только как хеш.

Проверка:

```bash
npm run lint
npm run build
```
