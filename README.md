# Family VPN

Family VPN — админ-панель одного администратора для нескольких VPN-серверов WireGuard.

Получатели VPN не регистрируются. Подписок и платежей нет. Конфигурации позже создаёт сам администратор.

## Стек

- Next.js 16
- TypeScript
- App Router
- Tailwind CSS
- SQLite через встроенный `node:sqlite` (Node.js 24)
- Go-агент
- Docker Compose + Caddy для HTTPS

## Этот этап

Работают локальная база, вход администратора, привязка агента и подготовка production-развёртывания.

Ещё не подключены трафик, handshake, выпуск `.conf` и QR-код. Удалённый VPS автоматически не меняется.

Развёртывание панели: [docs/deploy.md](docs/deploy.md).  
Подключение уже настроенного VPS: [docs/vps-connect.md](docs/vps-connect.md).  
Архитектура: [docs/architecture.md](docs/architecture.md).

После публикации релиза одна установочная команда печатается в `releases/INSTALL.txt`. Установщик сверяет контрольные суммы и не перезаписывает существующий `wg0`.

## Панель на Ubuntu 24.04

Новая панель ставится на свой VPS и получает HTTPS-сертификат Let's Encrypt на публичный IPv4. Сертификат профиля `shortlived` действует около 160 часов. Certbot 5.4 обновляет его сам, затем перезагружает только Caddy.

Репозиторий приватный. Токен и пароль в установщик не записываются. С машины, где уже есть доступ к GitHub, копируйте свежий clone. Рабочий каталог Windows не копируйте: в нём лежит локальная база.

Перед установкой на своём компьютере создайте ключ резервных копий. Приватный ключ остаётся только у вас. В команду попадает публичный ключ из вывода `age-keygen`, он начинается с `age1`.

```bash
age-keygen -o family-vpn-backup.key
git clone git@github.com:iaremadenis-dev/family-vpn.git
scp -r family-vpn root@PANEL_IP:/opt/family-vpn/app
ssh root@PANEL_IP bash /opt/family-vpn/app/panel/install-panel.sh --new --email you@example.com --backup-pubkey age1...
```

Если публичный адрес не совпадает с адресом на интерфейсе, добавьте `--ip A.B.C.D`. Установщик один раз печатает код активации и не пишет его в журнал. Откройте `https://A.B.C.D/login`, введите этот код и задайте пароль администратора. Пока кода нет, публичная страница не создаёт учётную запись.

Повторный запуск, если в `/var/lib/family-vpn/panel` уже есть база или `master.key`, останавливается и ничего не стирает.

Копия панели — отдельный архив `panel-*.tar.age`: согласованный снимок SQLite, `master.key`, служебный `panel.env`, идентификаторы серверов и агентов, версия схемы и контрольные суммы. Таймер снимает её каждые шесть часов и после изменения администратора, сервера, агента или конфигурации. Сердцебиения агента архив не запускают. Файл `/etc/family-vpn/backup.env` (образец — `panel/backup.env.example`) указывает любое S3-совместимое хранилище. Ключи доступа остаются в этом файле с правами `600`.

Если последней успешной отправки нет или ей больше 26 часов, проверка `backup-panel.sh --check-age` завершается с ошибкой. Текст ошибки не содержит ключей и содержимого базы.

Восстановление на чистый Ubuntu с другим IP. Приватный ключ `age` остаётся на компьютере администратора: там архив расшифровывается, а на новый сервер по SSH уходит только открытый tar.

```bash
bash panel/push-restore.sh \
  --host root@NEW_IP \
  --archive panel-....tar.age \
  --identity family-vpn-backup.key \
  --email you@example.com \
  --no-sudo
```

На сервере к этому моменту уже лежит копия репозитория в `/opt/family-vpn/app`, без файла ключа. Команда проверяет контрольные суммы, версию схемы и то, что `master.key` открывает клиентские секреты. Запись в каталог данных происходит только после этого. Если там уже есть другая база, она не меняется. Затем выпускается новый сертификат на новый IP. Адреса WireGuard-серверов и их peers не переписываются, агенты сами на новую панель не переключаются.

Файл `backup.env` для следующих копий копируется отдельно. Это ключи хранилища, не ключ `age`.

Архив самого WireGuard-сервера отдельный. На этом сервере, не останавливая интерфейс:

```bash
sudo bash panel/backup-wg.sh
sudo bash panel/backup-wg.sh --install-timer
```

В него входят `wg0.conf`, `agent.json` и unit агента, если он есть. На компьютере администратора архив открывается локально, а на сервер передаётся уже расшифрованный tar: `panel/restore-wg.sh --payload wg.tar --into /путь`. Эта команда не запускает WireGuard и не смешивается с архивом панели.

Установщик не останавливает `wg0`, не правит `wg0.conf` и не переписывает firewall. TCP 80 и 443 должны быть доступны для выпуска сертификата.

Продление проверяется таймером `family-vpn-cert-renew.timer` дважды в сутки и выпускает новый сертификат, когда до конца срока остаётся меньше двух суток. Ошибка пишется в журнал службы и в `/var/lib/family-vpn/cert-renew.status`.

На чистой машине для проверки без доверенного сертификата можно добавить `--staging`. Такой сертификат агенты не примут. На рабочий VPN-сервер эту команду запускать не нужно.

## Запуск локально

```bash
npm install
npm run dev
```

База — каталог `data/` или `FAMILY_VPN_DATA_DIR`. За прокси: `FAMILY_VPN_TRUST_PROXY=1`.

## Проверки

```bash
npm run lint
npm run build
npm run test:pairing
bash scripts/verify-production-ready.sh
```

Протокол агента: `go test ./...` в каталоге `agent`.  
Сборка релиза агента: `FAMILY_VPN_PUBLIC_URL=https://panel.example.com bash scripts/build-release.sh`.
