# Family VPN

Family VPN — админ-панель для управления несколькими VPN-серверами на WireGuard.

Один администратор вручную готовит конфигурации. У каждой конфигурации один сервер, а один сервер может обслуживать много конфигураций. Панель не привязана к конкретному VPS: позже её можно разместить на собственном сервере.

Пользовательских аккаунтов VPN, подписок и платежей нет.

## Стек

- Next.js 16
- TypeScript
- App Router
- Tailwind CSS
- ESLint
- npm

## Этот этап

В репозитории только проект, навигация и интерфейс на демонстрационных данных.

Не подключены:

- VPS и WireGuard
- база данных
- авторизация
- внешние API
- генерация ключей и файлов `.conf`

Кнопки без серверной части помечены как демонстрационные. Они меняют только текущее окно браузера. Скачивание `.conf` и QR-код намеренно ничего не создают.

Адреса серверов в примере взяты из диапазонов документации RFC 5737 и не являются рабочими узлами.

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Проверка линтера:

```bash
npm run lint
```
